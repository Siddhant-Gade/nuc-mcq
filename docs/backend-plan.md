# Backend Implementation Plan

## Planning Rules

Implement one phase at a time. Before each phase, reread this file and `docs/backend-reference.md`, inspect affected code, make only scoped changes, run the listed validation, then update both documents. Product decisions marked **BLOCKED** require confirmation; do not invent them.
